Agent Coding Input

A sophisticated input component for submitting coding instructions to the AI agent. Supports plan/edit modes, provider selection, file attachments, and command palette integration.

Overview

The Agent Coding Input component provides a comprehensive interface for users to interact with the Coder AI assistant. It features a rich text input with special character support, mode selection for planning vs. direct editing, AI provider configuration, and git branch selection for context-aware code generation.

Key features include file reference via @mentions, command palette via /commands, and an AI-powered text improvement feature for enhancing user prompts.

Usage

Basic usage with default configuration:

<AgentInput mode="plan" provider="anthropic" model="claude-opus-4" branch="main" onSend={(instruction) => handleSend(instruction)} />

API Reference

Props

Prop Type Default Description
mode 'plan' | 'edit' 'plan' Initial mode selection
provider string 'anthropic' AI provider ID
model string 'claude-opus-4' Model identifier
branch string 'main' Git branch for context
onSend (instruction) => void — Callback when send is clicked
